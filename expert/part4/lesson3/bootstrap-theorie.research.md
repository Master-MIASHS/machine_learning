## RQ1 — Algorithme du bootstrap non paramétrique

**VÉRIFIÉ — Efron (1979)**, « Bootstrap Methods: Another Look at the
Jackknife », *The Annals of Statistics* 7(1), 1–26 (The 1977 Rietz
Lecture). PDF lu en intégral (copie publique :
https://sites.stat.washington.edu/courses/stat527/s14/readings/ann_stat1979.pdf) :

- Problème (§2) : « Given a specified random variable R(X, F), possibly
  depending on both X and the unknown distribution F, estimate the
  sampling distribution of R on the basis of the observed data x. »
- Méthode (§2), un échantillon de taille `n` de `F` inconnue :
  1. construire la loi empirique `F̂_n` (masse `1/n` en chaque
     `x_1,…,x_n`) ;
  2. tirer un **échantillon bootstrap** `X* = (X_1*,…,X_n*)` de taille `n`
     dans `F̂_n` — « the values of X* are selected **with replacement**
     from the set {x_1,…,x_n} » (contraste explicitement opposé au
     jackknife : « drawing samples of size n−1 **without** replacement ») ;
  3. approximer la loi d'échantillonnage de `R(X,F)` par la
     **loi bootstrap** de `R* = R(X*, F̂_n)` (`F̂_n` fixé à sa valeur
     observée).
- Argument de justification (Fisher consistency) : « the distribution of
  R*, which in theory can be calculated exactly once the data x is
  observed, equals the desired distribution of R if F = F̂_n ».
- **Méthode 2 (Monte Carlo)** : « Repeated realizations of X* are
  generated by taking random samples of size n from F̂_n … and the
  histogram of the corresponding values R(x*¹,F̂_n), R(x*²,F̂_n), … is
  taken as an approximation to the actual bootstrap distribution. »
- **Régression (§7)** : modèle `x_i = g_i(θ) + ε_i`, résidus
  `ε̂_i = x_i − g_i(θ̂)` ; bootstrap : `x_i* = g_i(θ̂) + ε̂_i*`
  (resamplage des résidus, les `g_i(θ̂)` fixes). Pour le modèle linéaire
  `g_i(θ) = c_iθ` (matrice `C`, `G = CᵀC`) : la loi bootstrap de `θ̂*`
  a covariance ≈ `σ̂²G⁻¹`, « agrees with traditional theory, except
  perhaps in using the estimate σ̂² for σ² ».

**croisé — Efron (1982)**, *The Jackknife, the Bootstrap and Other
Resampling Plans*, CBMS-NSF Regional Conference Series in Applied
Mathematics, vol. 38, SIAM, 1982, DOI 10.1137/1.9781611970319. Page
SIAM lue : ch. 5 « The Bootstrap » (« conceptually the simplest of all
the techniques considered here … connection with the jackknife is made in
Chapter 6 »). Traitement systématique + justification heuristique ;
seules les affirmations de la page SIAM sont VÉRIFIÉES, le contenu

**Croisé pour le cas régression par paires** : resamplage des paires
`(x_i, y_i)` (case resampling) — la variante « moderne » du bootstrap de
régression ; sa validité est celle de Freedman (1981), voir RQ2.

## RQ2 — Consistance (Efron 1982 ; Bickel & Freedman 1981)

**VÉRIFIÉ — Bickel & Freedman (1981)**, « Some Asymptotic Theory for the
Bootstrap », *The Annals of Statistics* 9(6), 1196–1217,
DOI 10.1214/aos/1176345637. PDF lu en intégral (OCR d'une copie publique,
23 pages ; les énoncés ci-dessous sont relus ligne à ligne, l'OCR est
bruyant mais les numéros de théorèmes et les structures sont
inambigus) :

- Résumé (p. 1196) : « Efron's "bootstrap" method of distribution
  approximation is shown to be asymptotically valid in a large number of
  situations, including t-statistics, the empirical and quantile
  processes, and von Mises functionals. Some counter-examples are also
  given, to show that the approximation does not always succeed. »
- **Théorème 2.1** (§2, moyenne) : `X_1, X_2, …` i.i.d. de variance
  finie positive `σ²`. Le long de presque toutes les suites
  d'échantillons, conditionnellement à `(X_1,…,X_n)`, quand
  `m, n → ∞` : (a) la loi conditionnelle de
  `√m (X̄_m* − X̄_n)` converge faiblement vers `N(0, σ²)` ;
  (b) `s_m*² → σ²` en probabilité conditionnelle. Conséquence : le
  pivot bootstrap `Q* = √m (X̄_m* − X̄_n)/s_m*` a la même limite que le
  pivot classique `Q_n` : `N(0,1)`.
- **Théorème 2.2** (§2) : version multimensionnelle — la loi
  conditionnelle de `√m ( (1/m)ΣX_i* − X̄_n )` converge vers la normale
  de covariance **théorique** ; la matrice de covariance empirique
  bootstrap converge en probabilité conditionnelle vers la matrice
  théorique.
- **Formulation générale (fin §2)**, reformulation par B&F du principe
  d'Efron : « If the law of Z_n{(X_1,…,X_n), F} tends weakly to a limit
  as n → ∞, then the conditional distribution of Z_m*{(X_1*,…,X_m*),
  F̂_n} given (X_1,…,X_n) tends weakly to the same limit law with
  probability one as m, n → ∞. »
- **Conditions de succès (§6, (6.1a)–(6.1c))** : le bootstrap fonctionne
  si (a) `R_n{(Y_1,…,Y_n); G}` converge faiblement vers `g(G)` pour tout
  `G` d'un voisinage de `F` ; (b) la convergence est **uniforme** sur ce
  voisinage ; (c) `G ↦ g(G)` est continue. « In the examples of this
  section, the bootstrap fails because uniformity does not hold on any
  usable neighborhoods. »
- **§7 (Other work)** : « Freedman (1981) has pursued the use of the
  bootstrap for least squares estimates in regression models when the
  number of parameters is fixed, and arrived at results very similar to
  those obtained for means in the one-sample problem. »

**VÉRIFIÉ — Freedman (1981)**, « Bootstrapping Regression Models »,
*The Annals of Statistics* 9(6), 1218–1228, DOI 10.1214/aos/1176345638
(page Project Euclid lue ; résumé) : « The regression and correlation
models are considered. **It is shown that the bootstrap approximation to
the distribution of the least squares estimates is valid, and some error
bounds are given.** » — c'est le résultat de consistance spécifique à
`β̂` (resamplage des paires `(X_i, Y_i)`, nombre de paramètres fixé).
Le corps de la preuve n'a pas été relu (paywall) : pour le panneau,
citer le résumé + le renvoi de B&F 1981 §7 suffit.

**UNVERIFIED** : les hypothèses techniques exactes de Freedman (1981)
(design fixe vs aléatoire, moments des erreurs). Le panneau doit
formuler le résultat au niveau du résumé (« sous des conditions
légères sur le modèle et le nombre de paramètres, la loi bootstrap de
β̂* − β̂ converge vers la loi d'échantillonnage vraie de β̂ − β ») et
ne pas inventer d'hypothèses fines.

## RQ3 — Percentile vs studentized

**croisé** — Efron & Tibshirani (1993), *An Introduction to the
Bootstrap*, Chapman & Hall / CRC, Monographs on Statistics and Applied
Probability 57 (livre, non relu ; les formules sont croisées sur une
source secondaire qui cite équations et pages exactes) :

- **Basic / reverse percentile** (Davison & Hinkley 1997, eq. 5.6 p. 194) :
  `(2θ̂ − θ*_{(1−α/2)}, 2θ̂ − θ*_{(α/2)})`
- **Percentile** (E&T 1993, eq. 13.5 p. 171 ; D&H 1997, eq. 5.18 p. 203) :
  `(θ*_{(α/2)}, θ*_{(1−α/2)})`
- **Studentized / bootstrap-t** (E&T 1993, eq. 12.22 p. 160 ; D&H 1997,
  eq. 5.7 p. 194) :
  `(θ̂ − t*_{(1−α/2)}·sê_θ, θ̂ − t*_{(α/2)}·sê_θ)` avec
  `t* = (θ̂* − θ̂)/sê_{θ*}` ; « the studentized test enjoys optimal
  properties as the statistic that is bootstrapped is pivotal ».
- Caveat percentile : « will work well in cases where the bootstrap
  distribution is symmetrical and centered on the observed statistic …
  if the bootstrap distribution is non-symmetric, then percentile
  confidence intervals are often inappropriate » ; petit échantillon :
  pour la variance, `n = 20`, niveau nominal 90 % → couverture réelle
  78 %.
- Hiérarchie de précision (cadre DiCiccio & Efron, discuté par Hall) :
  première ordre = erreur de couverture `O(n^{−1/2})` ; deuxième ordre =
  `O(n^{−1})` ; « second-order correct » pour le point critique =
  `O_p(n^{−3/2})`.

**VÉRIFIÉ — Efron (1987)**, « Better Bootstrap Confidence Intervals »,
*Journal of the American Statistical Association* 82(397), 171–185
(résumé JSTOR lu) : les intervalles BCa « results in second-order
correctness in a wide variety of problems ».

**UNVERIFIED** : le taux précis « le percentile a une erreur de
couverture de l'ordre de `O(√(log n)/n)` tandis que le studentized/BCa
ont `O(1/n)` » (attribué à Efron 1987 / E&T 1993 ch. 14 dans la
littérature secondaire, non relu dans le texte primaire cette session).
Le panneau doit rester qualitatif : le percentile est seulement
premier ordre ; le studentized (comme le BCa) est deuxième ordre, donc
asymptotiquement plus précis, et corrige l'asymétrie. Ne pas écrire le
taux `O(√(log n)/n)` comme fait vérifié.

## RQ4 — Wild bootstrap (hétéroscédasticité)

**VÉRIFIÉ — Wu (1986)**, « Jackknife, Bootstrap and Other Resampling
Methods in Regression Analysis », *The Annals of Statistics* 14(4),
1261–1295, DOI 10.1214/aos/1176350142 (page Project Euclid lue ; résumé) :
« Three bootstrap methods are considered. **Two are shown to give biased
variance estimators** and one does not have the bias-robustness property
enjoyed by the weighted delete-one jackknife. **A general method for
resampling residuals is proposed. It gives variance estimators that are
bias-robust.** » — i.e. sous hétéroscédasticité, le resamplage naïf des
résidus (et le case resampling) donne des estimateurs de variance
biaisés ; la méthode « wild » corrige cela.

**croisé** — mécanisme (source secondaire citant Wu 1986 / Mammen 1993) :
`y_i* = ŷ_i + ε̂_i · v_i` où `v_i` est un poids aléatoire centré de
variance 1 (Rademacher `±1` ; distribution de Mammen à deux points
`−(√5−1)/2 ≈ −0,618` avec proba `0,7236` et `+(√5+1)/2 ≈ +1,618` avec
proba `0,2764`). Les régresseurs restent fixes ; contrairement au
resamplage i.i.d. des résidus, le poids garde la structure locale de
variance `ε̂_i²`.

**VÉRIFIÉ (bibliographie) — Mammen (1993)**, « Bootstrap and Wild
Bootstrap for High Dimensional Linear Models », *The Annals of
Statistics* 21(1), 255–285, DOI 10.1214/aos/1176349025 (page JSTOR lue :
« two bootstrap procedures are considered for the estimation of the
distribution of linear contrasts and of F-test statistics in high
dimensional linear models »).

## RQ5 — Limites : fonctionnels non lisses

**VÉRIFIÉ — Bickel & Freedman (1981), §6 « Counter-examples »** (lu en
intégral, OCR) :

- **Contre-exemple 2 : la maximum et les spacings.** `F` uniforme sur
  `(0, θ)`, `θ` = bord supérieur du support. Le pivot usuel
  `n(θ − X_{(n)})/θ` a pour limite exponentielle standard. Le
  substitut bootstrap naturel `n(X*_{(n)} − X_{(n)})/X_{(n)}` « **does
  not work** » :
  `P{ n(X*_{(n)} − X_{(n)}) = 0 | F̂_n } → 1 − 1/e ≈ 0,63` ; plus
  généralement, la loi conditionnelle de
  `n(X_{(n)} − X*_{(n−k+1)})/X_{(n)}` **n'a pas de limite faible**
  (`limsup = ∞`, `liminf = 0` p.s. pour chaque `k`). « The problem is
  the lack of uniformity in the convergence of F̂_n to F. » Et le
  **bootstrap paramétrique** (`F_θ̂` = uniforme sur `(0, X_{(n)})`)
  fonctionne : `n(X*_{(n)} − X*_{(n−1)})/X*_{(n)}` suit la même limite
  exponentielle.
- **Contre-exemple 1 : une U-statistique.** Sans la condition von Mises
  (6.5), le bootstrap peut échouer : `|R_{n2}(X_1*,…,X_n*; F̂_n)|` peut
  tendre vers ∞ en probabilité (exemple : `F` uniforme sur `(0,1)`,
  noyau singulier en la diagonale).

**VÉRIFIÉ — la médiane EST un cas de succès, pas d'échec.**
Bickel & Freedman (1981), **Proposition 5.1** (§5 « The quantile
process ») : si `F` a une médiane unique `μ` et `f` a une dérivée
positive continue au voisinage de `μ` (forme la plus faible : `μ` unique
et `f(μ) > 0`), alors, conditionnellement aux données,
`√n (m* − m)` converge faiblement vers `N(0, 1/(4f(μ)²))` — la même
limite que `√n (m − μ)`. Le bootstrap est donc **consistant pour la
médiane** sous `f(μ) > 0`. Théorème 5.1 du même § : même résultat pour
le processus de quantiles `√n(F̂_n^{−1} − F^{−1}) ⇒ B/(f∘F^{−1})`.

**VÉRIFIÉ — Efron (1979), §3** : le bootstrap estime (asymptotiquement)
correctement la variance de la médiane échantillonnale — « a case where
the jackknife is known to fail ». C'est le jackknife, pas le bootstrap,
qui échoue pour la médiane.

**⚠ Correction du prérequis du brief** : le brief propose « la médiane »
comme exemple de fonctionnel non lisse pour lequel le bootstrap peut
échouer. Les sources primaires vérifiées disent le contraire : la médiane
est couverte par la Proposition 5.1 (consistance, `f(μ) > 0`) ; le
contre-exemple vérifié est **la maximum** (§6). Le panneau doit présenter
la maximum comme exemple d'échec, et mentionner la médiane comme cas
démontre (avec la condition `f(μ) > 0`).

**UNVERIFIED** : le cas `f(μ) = 0` (densité qui s'annule en la médiane,
taux de convergence `n^{1/3}` au lieu de `√n`, et échec de la
studentization usuelle) : cohérent avec l'état de la littérature
secondaire, mais **hors des hypothèses de B&F 1981** et non relu dans une
source primaire cette session. Si le panneau le mentionne, il doit rester
en une phrase prudente et le marquer comme tel ; sinon le laisser tomber.
De même : l'échec du bootstrap pour la moyenne quand la variance est
infinie (résultat d'Athreya) — non vérifié dans la source primaire cette
session ; mentionner au plus en note, ou ne pas mentionner.

## RQ6 — Pont vers le bagging

**VÉRIFIÉ (source du cours)** — `course_sources/typst/regularization.typ`,
ch. 4 : Définition 4.5 — échantillon bootstrap : n tirages avec remise ;
`(1−1/e) ≈ 63,2 %` des points originaux présents, `1/e ≈ 36,8 %` absents ;
Algorithme 4.1 (bagging : M échantillons bootstrap → M modèles →
moyenne/vote) ; Théorème 4.2 (variance `σ²/M` si décorrélés). Enseigné sur
le site : Partie V, leçon 1.

**VÉRIFIÉ (coïncidence de constantes)** — Bickel & Freedman (1981), §6 :
`P{X*_{(n)} = X_{(n)} | F̂_n} → 1 − 1/e ≈ 0,63` : la même constante
`(1−1/e)` qui gouverne le bagging (point présent au moins une fois dans
l'échantillon bootstrap) est celle qui fait que le bootstrap maximum
coïncide avec l'observation maximale avec probabilité ≈ 63 %.
